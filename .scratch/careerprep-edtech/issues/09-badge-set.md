# 09 — Badge set definition

Type: grilling
Status: open
Blocked by: 05

## Question

Fixed set in code, roughly 8-10 badges. Define them.

- What is each badge, and what is its exact trigger condition against the progression model from ticket 05?
- What is the mix across the axes that matter: consistency (streaks), volume (solves), depth (hard questions), breadth (industries/categories), completion (roadmaps), and speed (timed assessment)?
- Which are one-shot and which are repeatable/tiered?
- Which are visible-but-unearned (a goal to chase) versus hidden-until-earned (a surprise)?
- Are any badge triggers gameable given the anti-farming decision in ticket 06?
- Do badges award XP, or are they purely symbolic?
- Which badges appear on the public profile, and in what order?

Deliverable: the badge table — name, trigger, tier, visibility, XP.
