# 04 — Funnel event taxonomy and CTA placement rules

Type: grilling
Status: open
Blocked by:

## Question

Primary metric is course enrollments. Define the funnel precisely enough that `funnel_events` can be designed to measure it.

- What are the named stages from anonymous arrival to enrollment, and what event marks each transition?
- What is the **struggle trigger**, exactly? (N failed submissions on one question? time-on-question? hint exhaustion?) It is the highest-intent cross-sell slot, so the threshold is a real decision.
- What is the event shape — actor (guest session id vs user id), event name, context, source surface, timestamp?
- Attribution: how is an enrollment traced back to the question / roadmap / CTA that produced it? Last-touch, first-touch, or full path?
- Which surfaces carry which offers: completion screen, lobby sidebar, struggle trigger, checkpoint failure, certificate page. One offer each, or competing offers ranked?
- What is the frequency cap so moderate aggression stays moderate?

Deliverable: stage list, event taxonomy, trigger thresholds, and a surface→offer matrix.
